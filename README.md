# 🎁 Muskurahatt: A Gifting Story, Now in Your Pocket

> *"Muskurahatt" means "a smile." Every gift we make is built to bring one.*

---

## 📖 Chapter 1: Once Upon a Time

In our third year of university, a few friends had a simple idea: **what if gifts felt more personal?**

So we started **Muskurahatt**, a custom gifting business. We made:

- 🎀 Gift boxes
- 🧺 Gift baskets
- ✨ Acrylic gift boxes
- 💐 Bouquets
- 💌 Cards
- 🎁 Hampers
- 👑 Premium gifts

Orders came in through chats and calls. It was fun, but also messy. That's when we asked ourselves: **why not build an app?**

---

## 📱 Chapter 2: The App is Born

For our **Mobile App Development** course project, we built the Muskurahatt app in **Flutter**.

Imagine you want to surprise your best friend:

1. 👀 **Open the app** and browse our gift collection
2. 💝 **Pick a gift** you love and check its details
3. 🛒 **Add it to your cart**
4. ✅ **Place your order**, and a smile is on its way!

## 🚀 Chapter 6: Try It Yourself

Want to run the app on your own computer?

1. Install [Flutter](https://docs.flutter.dev/get-started/install)
2. Clone this repo:
```
git clone https://github.com/YOUR_USERNAME/muskurahatt-app-flutter.git
```
3. Go into the folder:
```
cd muskurahatt-app-flutter
```
4. Get the packages:
```
flutter pub get
```
5. Run the app:
```
flutter run
```
